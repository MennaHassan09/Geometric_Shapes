# Geometric Shapes Drawing and Area Calculation

## Project Overview

A Java project that represents geometric shapes using object-oriented programming. It calculates shape areas and draws shapes using Java graphics.

## Features

- Circle and cube classes.
- Area calculation for supported shapes.
- Colored shape drawing.
- Input file for shape data.
- Output file for result

## Technologies

- Java
- Object-Oriented Programming (OOP)
- NetBeans IDE

## How to Run

1. Open the project in NetBeans.
2. Make sure `inPut.txt` is available in the expected working directory.
3. Run the main project class.
